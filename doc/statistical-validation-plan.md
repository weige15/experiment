# Review-driven statistical validation, before inspecting formal results

The formal GPU runs are in progress; no partial formal answers or sensitivity values have been inspected. `doc/statistics-review.md` identified a non-exact residual permutation and a content-boundary corner case. The original measurement protocol and all raw data remain unchanged.

## Changes to validate
1. Keep the original mean-normalized/log-linear residual permutation **as an exploratory approximate diagnostic only**, not confirmatory significance evidence. Its coarse bins do not make regression residuals exchangeable.
2. Add a stronger shape diagnostic: center and standardize each request's eight-group profile. This removes both arbitrary positive request-wide multiplicative scale and additive offsets of a fixed global group profile. Rankings/materiality remain independent necessary checks: correlation alone never proves different optimal groups.
3. Fit dataset-specific cubic functions of standardized log input length, with and without dataset-specific log BF16 output length. Output-length adjustment is a sensitivity analysis, not a claim of causal identification.
4. Use a nuisance-orthogonal, request-cluster wild **score** test for positive cross-wording shape association. Let R_A/R_B be profile residuals and M_B the residual-maker for wording B's covariates. Project Z=M_B R_A; source contributions are c_r=sum_g Z_rg R_B,rg. Observed score is sum(c_r). For the null distribution multiply HC2-adjusted contributions c_r/sqrt(1-h_B,rr) by independent source-level Rademacher signs, retaining all groups together. Studentize by sqrt(sum(c_HC2^2)); use an add-one one-sided p-value. This is an approximate, asymptotic wild-score procedure, **not an exact randomization test**. Holm-adjust the 16 planned metric×scope×output-control tests together.
5. Check null rejection rates before using those tests. Simulate 500 independent trials per scenario, 999 wild replicates/trial, fixed simulation seed 314159. Scenarios: homoskedastic independent profile errors; length-dependent heteroskedastic errors; nonlinear length-only nuisance; jointly input/output-dependent nuisance. Run at n=32 (one dataset) and n=96 (three datasets). Report rejection proportions and binomial confidence intervals, not only a pass flag. Add a shared-request-profile alternative to check power. These values are **synthetic method-validation results**, never model experiment evidence.
6. Retain uncertainty: these simulations cannot establish validity for arbitrary misspecification, asymmetry, dependence or unobserved confounding. If size is materially inflated (>0.08 in any predeclared null scenario), do not use this test as a significance gate; investigate the method rather than editing conclusions. Strong positive controls should be detected; a perfectly fixed profile must produce no residual signal.
7. Fix no-delimiter content boundary to `len(text)` (not `len(text.rstrip())`); the token-level whitespace filter already removes standalone whitespace. Include mixed-content/trailing-whitespace tokens. Whole tokens crossing a next-question delimiter remain excluded because token KL cannot be split into characters.

The decision to add these checks follows an independent methodological critique, not favorable/unfavorable formal results. Positive M1 evidence must still combine complete real measurements, noise-resolved replicated reversals, robustness outside formatting tokens, material same-budget effects and honest task-quality/oracle limitations.
